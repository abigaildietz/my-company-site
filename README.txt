M & N Vertical Stress Calculator

Deployment:
1. Upload index.html to any static web host (GitHub Pages, Netlify, cPanel, etc.).
2. No server-side code or dependencies are required.
3. Open index.html in a browser to test locally.

Inputs: uniform pressure q, width B, length L, depth z.
Output: m, n, influence factor I, and vertical stress increase qI.
The calculation is for stress beneath the corner of the entered rectangular loaded area.
